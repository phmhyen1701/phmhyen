# Nhãn Bear mẹ bé: quy tắc text overlay

> Nguồn: `Brand guildeline/Bear mẹ bé/` (Yan gửi 23/11/2026). Thông số đọc từ ảnh cài đặt CapCut, mã màu đo trực tiếp từ ảnh.
> Mã SP đã xác nhận dùng nhãn này: **5H02D24** (ảnh mẫu "Máy xay thủy tinh Bear / CH-5H02D24").

## 1. Font
Dùng chung với Bear Official, xem `rules/brand/chung.md`.
- **iCiel Supa Mega Fantastic Regular**: chữ viết tay (tên SP, dòng nhỏ trên sticker)
- **iCiel Supa Mega Fantastic Caps**: chữ in hoa đậm (nhãn tính năng, mã SP, số trên sticker)

## 3. Preset text (CapCut)
Quy luật chung của nhãn này: **chữ một màu + viền trắng dày + bóng đổ màu còn lại, không mờ, góc -45°**. Hồng và xanh cốm luôn đi cặp, đổi chỗ cho nhau giữa chữ và bóng.

### P1. Tên SP (chữ viết tay)
Ví dụ: "Máy xay thủy tinh Bear". Dùng ở cảnh hero, kết quả, CTA.
| Thông số | Giá trị |
|---|---|
| Font | iCiel Supa Mega Fantastic **Regular** |
| Cỡ | 18 |
| Màu chữ | `#FF7979` |
| Character / Line | 0 / -6 |
| Căn | Giữa |
| Stroke | `#FFFFFF`, độ dày 53 |
| Background / Glow | Tắt |
| Shadow | `#A1B520`, opacity 100%, blur 0%, distance 6, angle -45° |

### P2. Nhãn caps (mã SP, tính năng, chữ cong)
Ví dụ: "CH-5H02D24", "LƯỠI DAO SÁT ĐÁY", "DUNG TÍCH CỐI 300ML" (bản cong).
| Thông số | Giá trị |
|---|---|
| Font | iCiel Supa Mega Fantastic **Caps** |
| Cỡ | 12 (mã SP dưới tên SP và chữ cong có thể to hơn, Yan chỉnh theo khung) |
| Màu chữ | `#A1B520` |
| Character / Line | 0 / 0 |
| Căn | Giữa |
| Stroke | `#FFFFFF`, độ dày 50 |
| Background / Glow | Tắt |
| Shadow | `#FF7979`, opacity 100%, blur 0%, distance 11, angle -45° |
- **Chữ cong**: cùng preset P2, bật Curve trong CapCut, cong theo vật thể.

### P3. Pill ✅ tính năng (nền trắng)
Ví dụ: "✅ THỦY TINH CHỊU NHIỆT", "✅ LƯỠI DAO INOX". Cộng dồn từng dòng khi voice kể tính năng.
- Pill bo tròn nền trắng, icon ✅ tròn xanh `#87D001` đè lên đầu trái pill.
- Chữ Caps xanh cốm (`#90B00D` đo được), **không viền, không bóng**.

### P4. Pill so sánh ❌ / ✅ (nền màu)
Ví dụ: "❌ TRỮ ĐÔNG TIỆN" / "✅ RÃ ĐÔNG LÀM MẤT CHẤT".
- Pill xanh cốm `#9AB621` + chữ trắng Caps, bóng hồng mảnh.
- Pill hồng `#FF8585` + chữ trắng Caps, bóng xanh cốm mảnh.
- Icon ❌ đỏ `#FF0000` / ✅ xanh `#87D001` đè đầu trái pill.
